# Release Notes v2.4.0

## Fixes

### NetSuite export no longer fails on blank cost centers

CSV exports to NetSuite now keep the cost center column even when it is empty, so the import no longer fails for the whole file. No action needed; your next export uses the fix.

## Enhancement

### Receipt preview in mobile approvals

Approvers now see the receipt image directly in the mobile approval screen and in the push notification, so they can approve without opening a laptop.
